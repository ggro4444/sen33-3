# Day 5 — Signature Moves 與 Anti-patterns 候選（森33-3）

> 日期：2026-08-08 ｜ 方式：AI 從現站萃取候選，小白只選（Signature ≤4 個、Anti-pattern 6-10 個）

## Signature Moves 候選（選 2-4 個，成為全站「招牌動作」）

**S1. 滿版 Hero 照片 + 中央細字排版**
現站已有：全屏照片、黑罩漸層、白色大字距標題、細線分隔、雙 CTA。
意義：第一屏就確立「照片主角」的編輯式開場。

**S2. 信紙式 Host Message（手寫區 + 細金線 + 簽名）**
現站已有：上下金線框、手寫體 Klee One、左側細線 border-l、右下簽名、角落 MORI 33-3 圓章。
意義：全站最有人味、最有辨識度的區塊——「主人溫度」的具體化身。

**S3. 細線裝飾語言（金線/白線作為分隔與轉場）**
現站已有：w-[1px] 細線、gradient 細線、border-y section 分隔、SCROLL 指示線。
意義：以「線」取代「卡片/色塊」作為視覺分隔——這是現站不像模板的關鍵。

**S4. 大呼吸節奏（section 間距 py-32/48 + 慢速進場）**
現站已有：極大 section 間距、AnimatedSection 輕進場、hover 微浮起。
意義：閱讀像散步，是「慢」的來源。

**S5. 三層字體系統（襯線標題 / 手寫溫度 / 樸素正文）**
現站已有：Noto Serif TC + Klee One + 系統字，字距普遍拉大。
意義：字體本身就是品牌識別。

**S6. 印章/圓形裝飾元素（MORI 33-3 圓章）**
現站已有：Host Message 角落的圓形金邊印章。
意義：手工感細節，可延伸到其他頁（房號章、日期章）。

→ 我選（≤4 個）：＿＿＿＿

## Pack A — 整體氣質（Visual Personality）

**A. 溫暖 Editorial**
- 像翻一本好的旅行小誌；襯線標題、大留白、照片為主
- 現站最接近的方向

**B. 精品飯店 Luxury**
- 深色或低飽和、細襯線、大氣奢華、空間留白極致
- 會被誤認是高級飯店品牌

**C. Airbnb Modern**
- 清爽、卡片化、圓角、現代 UI 感、資訊方塊整齊
- 會被誤認是訂房平台模板

## Pack B — 照片 vs UI（Media Relationship）

**A. 大照片、少 UI**
- 照片佔畫面主導，按鈕/文字退後；UI 幾乎隱形
- 現站方向

**B. 照片放進規整卡片**
- 照片裁成統一比例放卡片，整齊但 UI 明顯
- 比較像平台/圖庫站

**C. 文字資訊主導**
- 照片當配角，文字/表格/資訊為主角
- 比較像說明書/部落格

## Pack C — 構圖（Composition）

**A. 不對稱 Editorial**
- 圖文交錯、左右不對稱、有編輯感
- 現站部分區塊已是（信紙式、印章角落）

**B. 中央對稱**
- 全部置中、莊重、穩定
- 現站 Hero 是，但整站全置中會太正式

**C. 規整 Card Grid**
- 網格卡片、一致尺寸、資訊方塊化
- 最「安全」但也最模板

## Pack D — 字體策略（Typography）

**A. Restrained Editorial（克制編輯感）**
- 襯線標題 + 樸素正文 + 字距拉開；有力但不張揚
- 現站方向

**B. Expressive（表現型）**
- 超大標題、斜體、裝飾字、強烈字體個性
- 適合時尚/藝文品牌，對民宿可能太搶

**C. UI-Functional（現代 UI 字）**
- 無襯線、清楚、功能性；像 SaaS 產品
- 會失去溫度與編輯感

→ 最像我們：＿ ｜ 可接受：＿ ｜ 不要：＿ ｜ 原因：

## Pack E — 空間密度（Density）

**A. 慢節奏 / 大呼吸**
- section 間距巨大、資訊稀疏、閱讀像散步
- 現站方向（py-32/48）

**B. 中等**
- 適度留白、資訊較密集、節奏中等

**C. 資訊密集**
- 一屏塞多內容、快速瀏覽
- 像電商/入口網站，民宿用會失去悠閒感
